  The Problem

  1. @temporalio/core-bridge is a native Rust module that needs to be compiled
  2. No prebuilt binary exists for ARM64 Windows (aarch64-pc-windows-msvc)
  3. Cargo (Rust) is not installed on your system to compile from source

  This is a known limitation - Temporal SDK doesn't ship prebuilt binaries for ARM64 Windows.
