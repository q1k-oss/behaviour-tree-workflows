# Webhooks & Triggers Architecture

This document outlines how webhooks and triggers integrate with our architecture: Temporal, Behavior Trees, Active Pieces, and our database.

---

## Overview

### The Two Types of "Triggers"

| Type | Description | Example |
|------|-------------|---------|
| **Flow Triggers** | Start a new workflow when event occurs | "When Google Sheet row added, run workflow" |
| **Mid-flow Signals** | Wake up a waiting workflow with external data | "Wait for payment webhook, then continue" |

---

## Active Pieces Trigger Model

Active Pieces defines three trigger strategies:

```typescript
enum TriggerStrategy {
  POLLING,      // Periodically check for new items
  WEBHOOK,      // Receive HTTP callbacks
  APP_WEBHOOK   // Platform-level shared webhooks
}
```

### Lifecycle Hooks

```
onEnable    → (flow published)    → register webhook with third-party
run         → (webhook received)  → transform payload, return items
onDisable   → (flow unpublished)  → cleanup webhook registration
onHandshake → (verification)      → respond to challenge (Slack, etc.)
onRenew     → (cron-based)        → refresh expiring webhooks (Jira, etc.)
```

### Webhook Trigger Definition Example

```typescript
import { createTrigger, TriggerStrategy } from '@activepieces/pieces-framework';

const newRowTrigger = createTrigger({
  name: 'new_row',
  displayName: 'New Row Added',
  description: 'Triggered when a new row is added to a sheet',

  type: TriggerStrategy.WEBHOOK,

  props: {
    spreadsheetId: Property.Dropdown({ ... }),
    sheetId: Property.Dropdown({ ... })
  },

  // Called when flow is published
  onEnable: async (context) => {
    const webhookUrl = context.webhookUrl;  // Auto-generated by platform
    const response = await registerWebhookWithGoogle(webhookUrl, context.propsValue);
    await context.store.put('webhook_id', response.id);
  },

  // Called when webhook is received
  run: async (context) => {
    const payload = context.payload.body;
    // Transform and return array of items (each starts a workflow)
    return [payload];
  },

  // Called when flow is unpublished
  onDisable: async (context) => {
    const webhookId = await context.store.get('webhook_id');
    await deleteWebhookFromGoogle(webhookId);
  },

  // Optional: Handle verification challenges
  handshakeConfiguration: {
    strategy: WebhookHandshakeStrategy.BODY_PARAM_PRESENT,
    paramName: 'challenge'
  },

  onHandshake: async (context) => {
    return {
      status: 200,
      body: { challenge: context.payload.body.challenge }
    };
  }
});
```

### Polling Trigger Example

```typescript
const newEmailTrigger = createTrigger({
  name: 'new_email',
  displayName: 'New Email',
  type: TriggerStrategy.POLLING,

  props: {
    folder: Property.Dropdown({ ... })
  },

  onEnable: async (context) => {
    // Set polling schedule (default is 5 minutes)
    context.setSchedule({
      cronExpression: '*/5 * * * *',
      timezone: 'UTC'
    });
  },

  run: async (context) => {
    const lastFetch = context.store.get('lastFetchEpochMs') || 0;

    // Fetch emails since last poll
    const emails = await fetchEmailsSince(lastFetch);

    // Update last fetch time
    await context.store.put('lastFetchEpochMs', Date.now());

    // Return new items
    return emails;
  }
});
```

## Architecture Options

### Option 1: Active Pieces Triggers + Temporal Workflows (Recommended)

```
┌─────────────────────────────────────────────────────────────────────┐
│                         CONTROLPLANE                                 │
│                                                                      │
│  ┌─────────────────┐    ┌──────────────────┐    ┌────────────────┐  │
│  │ Webhook Endpoint │───▶│ Trigger Executor │───▶│ Temporal Client│  │
│  │ /webhooks/:id   │    │ (AP trigger.run) │    │ .start() or    │  │
│  └─────────────────┘    └──────────────────┘    │ .signal()      │  │
│                                                  └────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│                         TEMPORAL                                     │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────────┐ │
│  │  Workflow: ProcessGoogleSheetRow                                │ │
│  │                                                                 │ │
│  │  Input: { row: { orderId: "123", customer: "John" } }          │ │
│  │  ↓                                                              │ │
│  │  BehaviorTree.execute()                                         │ │
│  │  ├── ValidateOrder                                              │ │
│  │  ├── SendSlackNotification                                      │ │
│  │  └── UpdateCRM                                                  │ │
│  └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

**Flow:**
1. User creates flow with trigger "Google Sheets: New Row"
2. `onEnable` registers webhook with Google
3. Google sends webhook to `/webhooks/{flowId}`
4. Controlplane runs `trigger.run()` to transform payload
5. Controlplane starts Temporal workflow with payload
6. Behavior tree executes the workflow logic

### Option 2: Mid-Flow Webhook Signals

For workflows that need to **wait** for external events:

```
┌─────────────────────────────────────────────────────────────────────┐
│  Workflow: ProcessPayment                                           │
│                                                                      │
│  ┌──────────────┐   ┌───────────────────┐   ┌────────────────────┐  │
│  │ CreateInvoice│──▶│ WaitForWebhook    │──▶│ ProcessPayment    │  │
│  │              │   │ (Temporal Signal) │   │                    │  │
│  └──────────────┘   └───────────────────┘   └────────────────────┘  │
│                              ▲                                       │
└──────────────────────────────│───────────────────────────────────────┘
                               │
                    Stripe webhook: /webhooks/signals/{workflowId}
                               │
                    ┌──────────┴──────────┐
                    │ Controlplane        │
                    │ temporal.signal()   │
                    └─────────────────────┘
```

## Temporal Signal Integration

### Defining Signals in TypeScript

```typescript
import * as wf from '@temporalio/workflow';

// Define signal type
export const paymentReceived = wf.defineSignal<[PaymentPayload]>('paymentReceived');

// Workflow that waits for signal
export async function processOrderWorkflow(order: Order) {
  // Step 1: Create invoice
  await activities.createStripeInvoice(order);

  // Step 2: Wait for webhook signal
  let payment: PaymentPayload | null = null;
  wf.setHandler(paymentReceived, (payload) => {
    payment = payload;
  });

  // Wait until signal received or timeout
  await wf.condition(() => payment !== null, '24h');

  // Step 3: Continue with payment data
  await activities.fulfillOrder(order, payment);
}
```

### Signal-With-Start Pattern

Start a workflow AND send a signal atomically:

```typescript
await temporal.workflow.signalWithStart(processOrderWorkflow, {
  workflowId: `order-${orderId}`,
  taskQueue: 'btree-workflows',
  args: [orderData],
  signal: paymentReceived,
  signalArgs: [paymentData],
});
```

### Sending Signals from Controlplane

```typescript
// When webhook received for an existing workflow
const handle = temporal.workflow.getHandle(workflowId);
await handle.signal(paymentReceived, paymentPayload);
```

## Database Schema

```sql
-- Trigger configurations (which AP trigger to use)
CREATE TABLE workflow_triggers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID NOT NULL REFERENCES tenants(id),
  workflow_id UUID NOT NULL REFERENCES workflows(id),

  -- Active Pieces trigger info
  piece_name VARCHAR(100) NOT NULL,      -- 'google-sheets'
  trigger_name VARCHAR(100) NOT NULL,    -- 'new_row'
  trigger_props JSONB NOT NULL,          -- { spreadsheetId: "...", sheetId: 0 }

  -- Generated webhook info
  webhook_id UUID UNIQUE DEFAULT gen_random_uuid(),
  webhook_secret VARCHAR(64),            -- For HMAC validation

  -- State from onEnable (stored webhook registration)
  trigger_state JSONB,                   -- { googleWebhookId: "..." }

  -- Status
  status VARCHAR(20) DEFAULT 'disabled', -- disabled, enabled, error
  last_triggered_at TIMESTAMPTZ,
  error_message TEXT,

  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Trigger execution log
CREATE TABLE trigger_executions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  trigger_id UUID NOT NULL REFERENCES workflow_triggers(id),

  -- What was received
  payload JSONB NOT NULL,
  headers JSONB,

  -- What happened
  status VARCHAR(20) NOT NULL,           -- received, processed, failed
  workflow_run_id VARCHAR(255),          -- Temporal workflow ID
  error_message TEXT,

  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- For polling triggers: schedule configuration
CREATE TABLE trigger_schedules (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  trigger_id UUID NOT NULL REFERENCES workflow_triggers(id),

  cron_expression VARCHAR(100) NOT NULL, -- '*/5 * * * *'
  timezone VARCHAR(50) DEFAULT 'UTC',
  last_run_at TIMESTAMPTZ,
  next_run_at TIMESTAMPTZ,

  -- Deduplication state
  last_fetch_epoch_ms BIGINT DEFAULT 0,

  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- For mid-flow signals: track which workflows are waiting
CREATE TABLE workflow_signal_subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID NOT NULL REFERENCES tenants(id),

  -- Which workflow is waiting
  temporal_workflow_id VARCHAR(255) NOT NULL,
  signal_name VARCHAR(100) NOT NULL,

  -- Webhook endpoint for this signal
  webhook_id UUID UNIQUE DEFAULT gen_random_uuid(),
  webhook_secret VARCHAR(64),

  -- Metadata
  expires_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),

  UNIQUE(temporal_workflow_id, signal_name)
);

-- Indexes
CREATE INDEX idx_triggers_webhook ON workflow_triggers(webhook_id);
CREATE INDEX idx_triggers_tenant ON workflow_triggers(tenant_id);
CREATE INDEX idx_triggers_status ON workflow_triggers(status);
CREATE INDEX idx_schedules_next_run ON trigger_schedules(next_run_at);
CREATE INDEX idx_signal_subs_webhook ON workflow_signal_subscriptions(webhook_id);
CREATE INDEX idx_signal_subs_expires ON workflow_signal_subscriptions(expires_at);
```

## Controlplane API Design

### Webhook Receiver Endpoint

```typescript
// POST/GET /webhooks/:webhookId
app.all('/webhooks/:webhookId', async (req, res) => {
  const trigger = await db.workflow_triggers.findByWebhookId(webhookId);

  if (!trigger) {
    return res.status(404).json({ error: 'Webhook not found' });
  }

  // 1. Validate HMAC if configured
  if (trigger.webhook_secret) {
    const signature = req.headers['x-signature'];
    const expected = hmac(trigger.webhook_secret, JSON.stringify(req.body));
    if (signature !== expected) {
      return res.status(401).json({ error: 'Invalid signature' });
    }
  }

  // 2. Load Active Pieces trigger
  const piece = await loadPiece(trigger.piece_name);
  const triggerDef = piece._triggers[trigger.trigger_name];

  // 3. Handle handshake if needed (Slack challenge, etc.)
  if (triggerDef.handshakeConfiguration?.strategy !== 'NONE') {
    const isHandshake = checkHandshakeRequest(req, triggerDef.handshakeConfiguration);
    if (isHandshake && triggerDef.onHandshake) {
      const result = await triggerDef.onHandshake({
        payload: { body: req.body, headers: req.headers }
      });
      return res.status(result.status).json(result.body);
    }
  }

  // 4. Transform payload via trigger.run()
  const items = await triggerDef.run({
    payload: { body: req.body, headers: req.headers, status: 200 },
    store: createStore(trigger.id),
    auth: await getAuthForTrigger(trigger),
    propsValue: trigger.trigger_props
  });

  // 5. Log execution
  await db.trigger_executions.create({
    trigger_id: trigger.id,
    payload: req.body,
    headers: req.headers,
    status: 'received'
  });

  // 6. Start Temporal workflow for each item
  for (const item of items) {
    const workflowId = `${trigger.workflow_id}-${Date.now()}-${randomId()}`;

    await temporal.workflow.start('executeWorkflow', {
      workflowId,
      taskQueue: 'btree-workflows',
      args: [{
        workflowId: trigger.workflow_id,
        triggerId: trigger.id,
        payload: item
      }]
    });

    await db.trigger_executions.update({
      workflow_run_id: workflowId,
      status: 'processed'
    });
  }

  // 7. Update trigger stats
  await db.workflow_triggers.update(trigger.id, {
    last_triggered_at: new Date()
  });

  res.status(200).json({ received: items.length });
});
```

### Signal Webhook Endpoint

For mid-flow webhooks that signal existing workflows:

```typescript
// POST /webhooks/signals/:webhookId
app.post('/webhooks/signals/:webhookId', async (req, res) => {
  const subscription = await db.workflow_signal_subscriptions.findByWebhookId(webhookId);

  if (!subscription) {
    return res.status(404).json({ error: 'Signal subscription not found' });
  }

  // Check expiry
  if (subscription.expires_at && subscription.expires_at < new Date()) {
    return res.status(410).json({ error: 'Signal subscription expired' });
  }

  // Validate HMAC
  if (subscription.webhook_secret) {
    validateHmac(req, subscription.webhook_secret);
  }

  // Send signal to Temporal workflow
  const handle = temporal.workflow.getHandle(subscription.temporal_workflow_id);
  await handle.signal(subscription.signal_name, req.body);

  // Cleanup subscription (one-time use)
  await db.workflow_signal_subscriptions.delete(subscription.id);

  res.status(200).json({ signaled: true });
});
```

### Enable/Disable Trigger Endpoints

```typescript
// POST /api/triggers/:triggerId/enable
app.post('/api/triggers/:triggerId/enable', async (req, res) => {
  const trigger = await db.workflow_triggers.findById(triggerId);

  // Load Active Pieces trigger
  const piece = await loadPiece(trigger.piece_name);
  const triggerDef = piece._triggers[trigger.trigger_name];

  // Generate webhook URL
  const webhookUrl = `${process.env.BASE_URL}/webhooks/${trigger.webhook_id}`;

  // Create store for trigger state
  const store = createStore(trigger.id);

  // Call onEnable to register with third-party
  await triggerDef.onEnable({
    webhookUrl,
    store,
    auth: await getAuthForTrigger(trigger),
    propsValue: trigger.trigger_props
  });

  // Update status
  await db.workflow_triggers.update(triggerId, {
    status: 'enabled',
    trigger_state: await store.getAll()
  });

  res.json({ status: 'enabled', webhookUrl });
});

// POST /api/triggers/:triggerId/disable
app.post('/api/triggers/:triggerId/disable', async (req, res) => {
  const trigger = await db.workflow_triggers.findById(triggerId);

  const piece = await loadPiece(trigger.piece_name);
  const triggerDef = piece._triggers[trigger.trigger_name];

  // Restore store from saved state
  const store = createStore(trigger.id, trigger.trigger_state);

  // Call onDisable to cleanup
  await triggerDef.onDisable({
    store,
    auth: await getAuthForTrigger(trigger),
    propsValue: trigger.trigger_props
  });

  await db.workflow_triggers.update(triggerId, {
    status: 'disabled',
    trigger_state: null
  });

  res.json({ status: 'disabled' });
});
```

## Polling Triggers with Temporal Schedules

For triggers that don't support webhooks:

```typescript
// When polling trigger is enabled
async function enablePollingTrigger(trigger: WorkflowTrigger) {
  const piece = await loadPiece(trigger.piece_name);
  const triggerDef = piece._triggers[trigger.trigger_name];

  // Get schedule from trigger (default 5 min)
  let cronExpression = '*/5 * * * *';

  // Call onEnable which may set custom schedule
  const scheduleConfig = { cronExpression };
  await triggerDef.onEnable({
    setSchedule: (config) => {
      scheduleConfig.cronExpression = config.cronExpression;
    },
    store: createStore(trigger.id),
    auth: await getAuthForTrigger(trigger)
  });

  // Create Temporal schedule
  await temporal.schedule.create({
    scheduleId: `poll-${trigger.id}`,
    spec: {
      cronExpressions: [scheduleConfig.cronExpression]
    },
    action: {
      type: 'startWorkflow',
      workflowType: 'pollTriggerWorkflow',
      taskQueue: 'btree-workflows',
      args: [{ triggerId: trigger.id }]
    }
  });

  // Save schedule config
  await db.trigger_schedules.create({
    trigger_id: trigger.id,
    cron_expression: scheduleConfig.cronExpression
  });
}

// Polling workflow (runs on schedule)
export async function pollTriggerWorkflow(args: { triggerId: string }) {
  const trigger = await activities.getTrigger(args.triggerId);
  const schedule = await activities.getTriggerSchedule(args.triggerId);

  // Run polling logic
  const items = await activities.executePollTrigger({
    triggerId: trigger.id,
    lastFetchEpochMs: schedule.last_fetch_epoch_ms
  });

  // Start workflow for each new item
  for (const item of items) {
    await activities.startWorkflowForTrigger({
      workflowId: trigger.workflow_id,
      triggerId: trigger.id,
      payload: item
    });
  }

  // Update last fetch time
  await activities.updateTriggerSchedule(args.triggerId, {
    last_fetch_epoch_ms: Date.now(),
    last_run_at: new Date()
  });
}
```

## Behavior Tree Integration

### New Node: WaitForSignal

For mid-flow webhooks, add a node that creates a signal subscription and waits:

```yaml
type: Sequence
id: payment-flow
children:
  - type: IntegrationAction
    id: create-invoice
    props:
      provider: stripe
      action: create_invoice
      inputs:
        amount: "${bb.orderTotal}"

  - type: WaitForSignal
    id: wait-payment
    props:
      signalName: "payment_completed"
      timeout: "24h"
      outputKey: "paymentData"
      # Optionally expose webhook URL for third-party registration
      webhookUrlKey: "paymentWebhookUrl"

  - type: IntegrationAction
    id: send-confirmation
    props:
      provider: slack
      action: send_message
      inputs:
        channel: "#orders"
        text: "Payment received: ${bb.paymentData.amount}"
```

**Implementation Concept:**

```typescript
// btree/src/actions/wait-for-signal.ts
export interface WaitForSignalConfig extends NodeConfiguration {
  signalName: string;
  timeout?: string;        // e.g., "24h", "30m"
  outputKey?: string;      // Where to store signal data
  webhookUrlKey?: string;  // Expose webhook URL on blackboard
}

export class WaitForSignal extends ActionNode {
  protected async executeTick(context: TemporalContext): Promise<NodeStatus> {
    const { signalName, timeout, outputKey, webhookUrlKey } = this.props;

    // Check if signal already received (from previous tick or pre-set)
    const signalData = context.blackboard.get(`_signal:${signalName}`);

    if (signalData !== undefined) {
      // Signal received - store and continue
      if (outputKey) {
        context.blackboard.set(outputKey, signalData);
      }
      return NodeStatus.SUCCESS;
    }

    // First tick - register signal subscription
    if (!context.blackboard.get(`_signal_registered:${signalName}`)) {
      // This would call controlplane to create subscription
      // and get back a webhook URL
      const webhookUrl = await context.registerSignalSubscription({
        workflowId: context.workflowId,
        signalName,
        timeout
      });

      if (webhookUrlKey) {
        context.blackboard.set(webhookUrlKey, webhookUrl);
      }

      context.blackboard.set(`_signal_registered:${signalName}`, true);
    }

    // Signal not received yet - return RUNNING
    // Temporal workflow will pause here and resume when signal arrives
    return NodeStatus.RUNNING;
  }
}
```

## Architecture Decisions Summary

| Concern | Decision | Rationale |
|---------|----------|-----------|
| **Webhook triggers** | Controlplane receives → AP trigger.run() → Temporal workflow | Reuse AP trigger transformation logic |
| **Polling triggers** | Temporal Scheduled Workflows | Durable, handles failures, built-in retry |
| **Mid-flow webhooks** | Temporal Signals + WaitForSignal node | Native Temporal pattern, workflow stays running |
| **State storage** | DB `trigger_state` column | Mirrors AP's `context.store`, persists across restarts |
| **Deduplication** | `lastFetchEpochMs` for polling | Standard AP pattern, timestamp-based |
| **Webhook URLs** | `/webhooks/{webhookId}` | Unique per trigger, secret for validation |
| **Signal URLs** | `/webhooks/signals/{webhookId}` | One-time use, expires with workflow |
